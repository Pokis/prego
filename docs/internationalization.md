# Internationalization

English is the only complete launch language. Data structures are locale-ready, but partial translation of health information is not acceptable for public release.

## Adding a locale

1. Preserve canonical content IDs.
2. Translate every published timeline entry, essential, milestone and urgent record.
3. Use qualified medical translation and clinical review in the target language.
4. Set document and passage language correctly.
5. Localize date and number formatting without adding a location selector.
6. Verify route alternates, canonical tags and sitemap entries.
7. Test filters, local state, hydration and deep links in the locale.
8. Confirm that doctor/escalation wording is natural and safe in the target language.

Do not use machine translation as publication approval. It may assist a draft only when clearly marked and subsequently reviewed.
