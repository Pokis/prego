# Internationalization

English is the only complete launch language. Data structures are locale-ready; add complete editions rather than fragmented translated routes.

## Adding a locale

1. Preserve canonical content IDs.
2. Translate every published timeline entry, essential, milestone and urgent record.
3. Set document and passage language correctly.
4. Localize date and number formatting without adding a location selector.
5. Verify route alternates, canonical tags and sitemap entries.
6. Test filters, local state, hydration and deep links in the locale.
7. Confirm that doctor/escalation wording is natural and unambiguous in the target language.

Document the translation method and verify the rendered edition locally before publishing it.
